## Deployment changes being tested

This is the first integrated test package for the cleaned standalone deployment path:

- ZIP contents go directly into the **SD-card root**;
- no `esd/` wrapper;
- no `MHI2AltScreen/` wrapper;
- own QNX ARMv7 `sha256sum` helper;
- own QNX ARMv7 `tee` helper;
- no runtime dependency on M.I.B. `config/BASICS`, `apps/mounts` or `/apps/sbin`;
- no `sed` runtime dependency;
- deployment medium is explicitly remounted writable and write-tested;
- installed runtime remembers the SD/USB mountpoint and prefers it for persistent logs;
- if the deployment medium is unavailable during boot, runtime logging falls back to `/tmp` instead of blocking Auto-Direct;
- DisplayManager gate remains STOCK by default;
- Auto-Direct is prepared before reboot rather than hot-started during installation;
- initial navigation composition profile is `map-rich`.

## Deliberately excluded

- SafeArea-capable GEN2 candidate;
- dynamic ViewArea experiment;
- unvalidated Java policy work.

The current D2 same-session keyframe policy remains an explicit developer switch while its watchdog timing is still being tuned.

## Test order

1. Put the ZIP contents directly in the SD root.
2. Ensure exact NavIgnore is already installed or copy it to `payload/MIBR-NavIgnore.jar`.
3. Run `./install.sh --check`.
4. Only continue if every preflight item passes.
5. Run `./install.sh --apply`.
6. Reboot the unit.
7. Run `./status.sh`.
8. Confirm native STOCK VC behavior first.
9. Then test CarPlay navigation / Auto-Direct behavior.

This remains an SSH/recovery-capable developer release. The integrated installer/runtime packaging itself is the item now entering vehicle validation.
